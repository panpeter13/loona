# 🌙 LOONA

LOONA — приватный Telegram-бот для отслеживания женского цикла.

## Возможности

- 🌙 Учёт цикла
- ✨ Главный экран текущего статуса
- 📅 Динамический прогноз
- 🔔 Напоминания
- 👥 Режим партнёра
- 🌍 Мультиязычность (RU / EN / KO)

## Технологии

- Node.js
- Telegraf
- Supabase

## Установка

```bash
npm install
```

Создай `.env` по примеру `.env.example` и затем:

```bash
npm start
```

## Безопасная разработка и staging

Не запускайте локальную копию с `BOT_TOKEN` рабочего бота, пока Railway использует
тот же токен: Telegram разрешает только один long-polling процесс.

1. Создайте через BotFather отдельного бота, например `loona_cycle_test_bot`.
2. Скопируйте `.env.example` в `.env.local` и укажите токен тестового бота.
3. Используйте отдельный тестовый проект Supabase.
4. Установите `APP_ENV=staging`.
5. Проверяйте изменения в ветке `develop`, затем объединяйте её с `main`.

Локальный запуск тестового бота:

```bash
npm run start:dev
```

Рабочий Railway-сервис должен отслеживать только ветку `main`. Для постоянного
staging создайте второй Railway-сервис из того же репозитория, выберите ветку
`develop` и задайте ему отдельные `BOT_TOKEN`, `SUPABASE_URL` и
`SUPABASE_SECRET_KEY`.

### Диагностика

Команда `/status` доступна только `ADMIN_TELEGRAM_ID` и показывает версию,
окружение, доступность Telegram и Supabase, задержку базы и время работы процесса.
Критические ошибки записываются в Railway Logs без токенов и JWT-ключей.
