# 🌙 LOONA

LOONA — приватный Telegram-бот для отслеживания женского цикла.

## Возможности

- 🌙 Учёт цикла
- ✨ Главный экран текущего статуса
- 📅 Динамический прогноз
- 🔔 Напоминания
- 👥 Режим партнёра
- ❤️ Поддержка через Telegram Stars
- 🌍 Мультиязычность (RU / EN / KO)

## Технологии

- Node.js
- Telegraf
- Supabase

## Установка

```bash
npm install
```

Создай `.env` по примеру `.env.example` и затем:

```bash
npm start
```
